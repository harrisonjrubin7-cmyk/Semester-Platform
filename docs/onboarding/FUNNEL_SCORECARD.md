Third-party sources cited in the research report app-store page-view-to-install anywhere from about 8.6% to 34% depending on store, country, category and method. Track Semester's own cohort rates instead of adopting one market figure.

## Scorecard

- **Acquisition:** qualified visitors · role CTA click-through · preview start · demo/pilot inquiry.
- **Identity:** signup start · account created · verification · SSO success · account-linking success · recovery success.
- **Onboarding:** journey assignment · step completion · skip/abandon · resume · time to first app route · time to first value · activation in session / 24 h / 7 d.
- **Cross-platform:** Universal/App Link resolution · installed-app open · browser fallback success · handoff exchange success · destination restoration · install after activation · permission acceptance after value.
- **Retention and business:** D1/D7/D30 return · activated-user retention · student upgrade · buyer→discovery · discovery→pilot · pilot→annual contract · expansion.

## App-store friction

Context switch, listing mismatch, no reviews, download time, storage, permissions, repeated sign-in, deep-link loss, store account requirement, old versions, SSO loops in in-app browsers, early push prompts. Mitigations: complete browser experience; one message system; real web proof; handoff transactions; route restoration; system-browser SSO; prompt only at the moment of benefit.

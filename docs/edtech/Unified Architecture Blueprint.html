Unified Architecture Blueprint

Capability model, data isolation and API surfaces for IT review · Draft · October 2026

Draft for review by a licensed attorney and the institution’s privacy office. Not legal advice. Statuses describe what Semester has, not certifications it doesn’t hold.

1. Layers

LayerWhat it does
Platform coreIdentity, permissions, workflow, notifications, search, files, audit
Student OS, Studio, SocialStudent-facing products
Institution OSRegistrar, advising, campus services, staff consoles
Revenue and financeCheckout, billing, ledger, reconciliation
AI gatewayPolicy-checked, minimized, logged AI calls

2. Data isolation

  • Tenant ID on every row; row-level security in Postgres
  • Student-level authorization re-checked per request
  • Education records never in social or AI context by default
  • Separate egress path for approved AI processors; separate write path to the SIS

3. Hosting

Vercel (application) and Supabase (Postgres, auth, storage), US regions. Subprocessors in the register.

4. Detail

Full five-zone data flow, encryption zones and the SIS field map are in the prototype’s Trust workspace and the handoff package.

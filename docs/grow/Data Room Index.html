Fundraising data room index

What an investor or grant reviewer can ask for, where it lives, and its honest status. October 2026. Share via an access-controlled folder with view logging, never by email attachment.

Never in the data room: student records, pilot data, credentials, or anything covered by the institution's DPA. Pilot results appear only as approved aggregates.

3. Before opening the room

  1. Replace every "draft" with the reviewed version, or label it draft.
  2. Check every number cites a source or the finance model.
  3. Remove internal notes and battlecards.
  4. Turn on view logging and per-person links.
  5. Set expiry: 30 days, renewable.

4. Gaps to close first

  1. File formation documents and open the business bank account.
  2. Get attorney review on MSA, DPA and terms.
  3. Bind cyber and E&O insurance.
  4. Set pilot dates and a sponsor-approved metrics plan.

Contract Package Map

How every Semester agreement fits together without conflicting · Draft · October 2026

Draft for review by a licensed attorney and the institution’s privacy office. Not legal advice. Statuses describe what Semester has, not certifications it doesn’t hold.

1. Two paths, one set of definitions

PathDocumentsAcceptance
Self-serveTerms of Service + checkout disclosures (price, renewal, cancellation, refunds) + Privacy notice + AUP + Community Guidelines + AI transparency noticeClick-wrap with versioned acceptance record (user, version, time, IP)
InstitutionalOrder Form + MSA + schedules (Support, SLA if offered, Exit and portability) + DPA + Student Data Privacy Addendum or NDPA + Security Addendum + AI Addendum + SOW where services applySignatures from both parties; stored in the contract repository

2. Order of precedence (institutional)

  1. Student Data Privacy Addendum / NDPA (for education records)
  2. DPA (for other personal data)
  3. Order Form (commercial terms only)
  4. MSA
  5. Security Addendum and AI Addendum
  6. Schedules (Support, SLA, Exit)
  7. SOW (services only; never changes data or liability terms)
  8. Online policies, as of the signed version

3. Consistency rules

  • One definitions section, referenced everywhere: Customer Data, Education Records, Student Private Content, Subprocessor, AI Feature
  • No SLA unless uptime has been measured for 90 days
  • Order forms list only modules that are generally available; designed modules go in a roadmap letter, not the contract
  • AI Addendum repeats the AI Boundary Charter: no grades, records, enrollment or financial actions by AI
  • Exit schedule: export in open formats within 30 days, deletion within 60, backups 90, certificate on request
  • Every negotiated deviation goes in the exceptions register

4. Library

All agreements live in docs/legal/. Support Schedule, AI Addendum, Exit and Data Portability Schedule and Change Order Template now drafted in docs/legal/. Integration and API Terms are covered by Developer and API Terms.

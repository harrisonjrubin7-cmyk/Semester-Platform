2. Rule

Never add these together or quote one as “Semester has N screens.” Each measures a different scope. Until a generated source-of-truth registry deduplicates them with a timestamp and inclusion rules, quote the source and its scope: e.g. “281 prototype routes (6 Oct 2026)”.

3. To reconcile

  1. Choose one canonical screen key: workspace + route + state
  2. Map each catalog’s entries to that key; mark duplicates and sub-views
  3. Record inclusion rules (do module tabs count? do states count?)
  4. Generate counts with a timestamp from the mapping, not by hand
  5. Publish in MASTER_CURRENT_STATE.md; every other document links there instead of restating numbers

4. Implementation status

Every catalog entry is Concept, Designed, Documented or Prototype until a named repository, branch, test evidence and environment prove more. Nothing in this design project is Implemented, Tested, Deployed, Institution-authorized or Production-enabled.

Faculty Guide

Teaching with Semester · Draft · October 2026

Guide draft.

1. Set up a course

  1. Connect your LMS course (LTI) or start in Semester
  2. Set the grading policy: weights, drops, late and missing rules; publish a version
  3. Set each assignment’s AI rule: off, planning only, guided, or open

2. Grade and release

  • Graded is not released: students see scores only after you release
  • Overrides keep the original calculated value and need a reason
  • Final grades go to the registrar through the posting flow; changes after posting need a grade-change request

3. Instructor Assistant

Drafts announcements, FAQs from repeated questions, and rubric setups. Nothing publishes until you approve. It never grades or flags students.

# Lead and lifecycle operations

_Semester growth and onboarding · 2026-10-05 · Prototype: ui_kits/journey/index.html. Code: handoff/semester-platform (110_onboarding_growth.sql, lib/auth/return-path.ts, tests/onboarding.test.ts). Design-stage until code, tests and release evidence exist._

Request demo → short form (name, work email, organization, role, use case, follow-up consent) → work-email verification → account match → segment → scheduling → discovery → pilot design → security/procurement → contract → tenant provisioning → implementation onboarding.

Routing: founder for institutional leads during pilot stage; SLA 1 business day. Lifecycle: account-created, onboarding reminders (max 3), activation nudges, feature education, re-engagement, referral request after activation, premium (students, optional), renewal support, win-back. Every message has an unsubscribe and respects suppression lists.

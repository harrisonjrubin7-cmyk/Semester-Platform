Generated 2026-10-07 from the master document catalog. This package contains one Markdown draft for each catalog item marked `Not started` (68 total). Existing catalog entries recorded as drafts/existing material are intentionally excluded. The package does not change the catalog, source repository, external systems, or product status.

## Common activation standard

No draft becomes production-enabled merely by approval. For the relevant tenant, domain, and release scope, evidence must show: a named institutional authority and accountable owner; tenant isolation and capability enforcement; source/provenance and freshness visibility; accessibility review; privacy/security review; automated and workflow testing; monitoring and support readiness; reconciliation where authoritative data is involved; a tested rollback/recovery path; and recorded approval. Any legal, contractual, accounting, procurement, security, privacy, retention, accessibility, or institutional-policy decision requires qualified review before use.

## Evidence-state vocabulary

- Designed: requirements written.
- Implemented: code/configuration exists.
- Tested: reproducible test evidence exists.
- Deployed: artifact is in an environment.
- Institution-authorized: an accountable institution approved the specific scope.
- Production-enabled: all scoped release gates passed and the capability is enabled.

A status at one level does not imply any later level.

- `INDEX.md` — review order, inventory, and common governance.
- `drafts/` — individual document drafts.
- `review-register.csv` — owners, dependencies, and review tracking fields.

Employee handbook (starter)

For the first hires and contractors. Draft for counsel and payroll-provider review; state employment law varies.

Draft for review by counsel. At-will language, leave, benefits and state notices must be completed by counsel and the payroll provider.

1. How we work

  • Student agency over surveillance; evidence over hype; trust before shortcuts
  • Every customer promise has an owner; every public claim has evidence
  • Write it down: decisions in the decision log, work in /ops, code in PRs
  • Weekly operating review on Monday; focus blocks protected

3. Security rules everyone follows

  • MFA everywhere; company devices encrypted and auto-locked
  • Never put student data in tickets, chat, email, docs or AI tools
  • Report anything suspicious within 1 hour to security@
  • Access removed the same day you leave

Security Addendum

Exhibit to the Master Services Agreement · Draft for attorney review · Summarises the controls Semester commits to contractually.

Draft for review by a licensed attorney and a security professional.
AreaCommitment

DevelopmentCode review, automated tests, dependency scanning, no production data in development

Accessibility Conformance Report (draft)

VPAT® 2.5 INT format, WCAG 2.2 edition · Product: Semester pilot scope (student web app, advisor caseload, registrar desk, institution console) · Status: design-stage self-assessment, not yet tested. Final ACR requires the manual and assistive-technology tests in docs/build/Accessibility Test Plan.html.

Do not send this as a final ACR. Every "Supports" below is a design intent with an evidence pointer. Replace with tested results (axe + NVDA + VoiceOver + keyboard) before procurement.

Evaluation methods (planned)

  • Automated: axe-core in CI on every pilot route
  • Manual: keyboard-only pass, 200% and 400% zoom, 320 px reflow
  • Assistive technology: NVDA + Firefox, JAWS + Chrome, VoiceOver + Safari (macOS, iOS), TalkBack + Chrome
  • Cognitive: plain-language review, timeouts, error recovery

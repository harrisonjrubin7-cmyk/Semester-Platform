2. Not collected

  • Precise location (only with opt-in, never stored)
  • Health records, counseling notes, disciplinary details
  • Advertising identifiers or cross-site tracking
  • Biometrics (device sign-in stays on the device)
  • Payment card numbers (processor only)

3. Data flows

Institution systems → read-only connector → staging → validation → canonical tables → role-scoped read models → app. Writes go through audited command functions. Exports and deletions follow the DPA. Hosting: Vercel and Supabase, US regions.

4. Review

Updated with every migration that adds a table or column (CI check), and reviewed quarterly.

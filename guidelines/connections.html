One record, many surfaces

  1. An assignment is created once by the course.
  2. Courses, Calendar, Action Center, Master plan and Study reference it; none copy it.
  3. Study blocks point at it and stay private.
  4. Released results attach to it; Gradebook and Master plan both read them.
  5. Every change is a command → event → each surface updates once.

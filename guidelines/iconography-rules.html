Sizes · pick by context, not by taste

SizeWhereNote
15pxInline with 13–14px text, chips, table cellsDense rows, source chips

19pxList rows, side rail, menu itemsDefault
21pxPhone tab bar, page-header actionsTouch target stays 44×44
32pxEmpty states, onboarding onlyNever in dense UI

Drawing

Grid24×24, 2px live-area padding
Stroke1.5px at 24; never scaled below 1.25 visually
Caps and joinsRound
FillNone. Exception: star when favourited
ColourAlways currentColor; inherits text colour
Corners1–2px radius on rectangles, matching the drawn-corner tokens
Optical sizeSame glyph at every size; no separate small set

Colour

✓ DoText colour by default; secondary for decorative

Missing a glyph?

  1. Search the set (Iconography card) for an existing meaning.
  2. If none, take the matching Lucide icon at stroke 1.5.
  3. Add it to assets/icons/, the sprite and iconShapes.js.
  4. Flag it in the PR as “new glyph” for design review.
  5. One meaning per glyph: don’t reuse proof for “verified” and “document”.

Open questions, answered from the project as it stands

QuestionCurrent answer
Which registry is canonical?None yet. The master catalog (screens, roles, workflows) is the most complete source. The green register and finish register track capability status separately.
Which screens are bespoke versus archetype-only?See the live count above.
Which handoffs are executable and tested?The handoff SQL, pgTAP suites and API stubs have not been run against a database. All of them are specified, not tested.
Which AI inputs are permitted?The strict rule applies: no student records go to a model until a data eligibility matrix is approved and enforced.
Which navigation model is authoritative?Open. The readme names 5 destinations, the student kit uses 7 areas, and the phone tabs use 5 different ones.
Which prototype workflows persist beyond this device?None. Every prototype saves to this browser’s local storage only.
